# Passkey Cryptography and Adoption

A university technical writing assignment on passkeys, FIDO2/WebAuthn, and the security and adoption trade-offs of passwordless authentication. This repository contains the written assignment, not an authentication implementation or a published research paper.

## Read the assignment

[Passkeys_RicardoStraub.pdf](Passkeys_RicardoStraub.pdf)

## Topics covered

- The FIDO2/WebAuthn authentication flow and the role of public-key cryptography.
- How passkeys can resist phishing compared with password-based authentication.
- Trade-offs around syncing credentials across devices and platforms.
- Risks of falling back to older authentication methods in legacy systems.
- Considerations around hardware-bound identification and EU eIDAS/PSD2 requirements.

## Scope

This is a coursework-based technical analysis and discussion, not a legal opinion, formal regulatory assessment, novel cryptographic scheme, or working software prototype. Refer to the PDF for the full argument, qualifications, and its cited sources.
